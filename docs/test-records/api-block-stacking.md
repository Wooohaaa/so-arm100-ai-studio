# 机械臂 API 控制测试：红块叠放到蓝块

## 结果

通过。SO-100 简化仿真臂抓起红色方块并将其放到蓝色方块上；机械臂随后返回待机位。

## 方法

- 使用本机 `POST /api/command` 发送末端移动、夹爪开合和回零命令。
- 使用 `/api/state` 读取物体与机械臂状态，按返回的世界坐标核验放置结果。
- 本次是 API 控制测试，没有连接或调用大模型服务。

## 测量结果

- 红、蓝方块中心的水平偏差：约 **0.65 mm**。
- 两方块中心的垂直间距：约 **59.8 mm**，与 60 mm 方块叠放时的预期一致。

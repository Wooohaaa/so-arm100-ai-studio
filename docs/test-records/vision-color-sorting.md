# 纯视觉高阶任务：三色分拣

**日期：** 2026-11-02

**结果：** 通过

## 场景与任务

工作台上放有红、蓝、黄三个方块，桌面设有三种对应颜色的目标框。任务要求逐一辨认方块颜色、选择匹配目标、抓取并放入框内，最后让机械臂回到待机位。控制面板显示任务说明，目标框不参与物理碰撞，只作为清晰的视觉定位标记。

## 执行方式

- 使用两个不同的仿真视角：斜视和俯视，按 **V** 切换；分拣与最终核验过程中在这两个角度间观察。
- 每次抓取前用画面定位方块，每次放置后查看方块与目标框的相对位置；最终在机械臂回零后从斜视和俯视确认三组颜色匹配。
- 方块位置、夹爪对准和完成状态都只根据 Unity 渲染画面判断。没有读取 `GET /api/state`、物体世界坐标或仿真状态快照。
- `POST /api/command` 仅作为动作执行通道，用于末端移动、夹爪开合和回零。

## 结果

- 红色方块位于红色目标框内。
- 蓝色方块位于蓝色目标框内。
- 黄色方块位于黄色目标框内。
- 机械臂回到待机位后，两个视角均可看到三块物体与各自目标框对齐。

动作过程通过逐步移动、闭爪、目视观察、搬运、降低、松爪和再次观察完成。动作目标由当前画面像素和相机标定估算；没有用状态 API 修正方块位置。

## 工程范围

- 测试运行在 Unity 6000.6.7f1 Windows 仿真程序中，不涉及真实机械臂。
- 本次由助手根据仿真截图进行视觉判断并发送动作；AI 面板没有连接 LLM 服务，因此没有验证外部大模型规划。
- 此后的机械臂操作任务继续遵循视觉优先约束：画面用于感知和核验，控制 API 只负责执行命令。

# 纯视觉闭环测试：红块叠放到蓝块

## 结果

通过。释放红块并让机械臂回到待机位后，斜视画面中仍可见红色方块稳定地放在蓝色方块上。

## 视觉与控制方法

- 使用两种相机视角：初始斜视（约 24° 仰俯角）和俯视（约 58°）。按 **V** 切换；最终复核时切回斜视，因此总共只使用两个不同视角。
- 从渲染画面中估计红、蓝方块的图像中心，并通过已知相机视场与桌面平面把像素位置换算为末端移动目标。
- 抓取前后、抬升、搬运、释放和机械臂撤离后均查看画面；红块随夹爪抬起，以及机械臂撤离后的叠放状态，均由画面核验。
- `POST /api/command` 仅用于发送机械臂动作。全程没有调用 `GET /api/state`、读取方块世界坐标或用状态接口判断成功。

## 动作记录

1. 从初始斜视切到俯视，目视定位两块方块；先将夹爪移动到红块附近并闭合。
2. 画面显示红块随夹爪约 6 cm 抬升。一次 14 cm 抬升命令被 SO-100 肩关节限位拒绝，没有执行；之后改为小幅抬升。
3. 一次较高的蓝块上方过渡目标也因肩关节限位被拒绝。改用可达的较低路径，将红块移动到蓝块上方并张开夹爪。
4. 切回斜视确认放置；让机械臂回零并撤离后，红块仍留在蓝块上方。

## 测试边界

- 测试对象是 Unity 中的 SO-100 运动学仿真，不是实体机械臂。
- 视觉定位由本次助手从仿真窗口截图完成；机械臂动作通过本机控制 API 发送。AI 面板显示未连接模型服务，因此本次没有验证配置的 OpenAI 兼容服务或应用内 LLM 规划器。
- 为便于在计算机视觉操作中切换视角，新增了 **V** 键斜视/俯视切换，并重新构建了 Windows 播放器。
